# 同時凸 最適組み合わせ計算機

ブラウザー上で動作する、同時凸の組み合わせと持ち越し時間を計算する単一HTMLツールです。

候補者ごとの予定DMGから、残りHPを討伐できる組み合わせを探索し、持ち越しDMG基準の設定状況に応じて結果を並べ替えます。

## 最新バージョン

- **v0**
- 公開用ファイル: `index.html`
- バージョン保管用ファイル: `co_time_calc_optimizer_v0.html`

> GitHub Pagesで公開する場合は、`co_time_calc_optimizer_v0.html`を複製して`index.html`へ変更し、リポジトリの公開対象に配置してください。

## 主な機能

### 候補者管理

- 初期候補者は2人
- 候補者を動的に追加・削除
- 最低2人を維持し、2人のときは削除不可
- 候補者数の上限なし
- 参加者名、予定DMG、持越凸を設定
- 候補者一覧をクリップボードへコピー
- 現在の候補者数に応じたサンプル入力

### サンプル入力

- 残りHP: 90,000万
- 1: 50,000万
- 2: 53,000万
- 3: 48,000万
- 4: 22,000万、持越凸あり
- 5: 15,000万、持越凸あり
- 6: 54,000万
- 7: 45,000万
- 8: 19,000万、持越凸あり

候補者が8人未満の場合は、現在表示されている人数分だけ入力します。8人を超える場合は、上記8人分の設定を先頭から繰り返します。

### 組み合わせ計算

- 残りHPを討伐できる全組み合わせを計算
- 持ち越し下限・上限を指定
- 持越凸にチェックした参加者を最後の担当から除外
- 選択されなかった候補者を「【残】」として表示
- 選択されなかった候補者の合計を「残総DMG」として表示
- 結果行から詳細を展開

### 持ち越しDMG基準

持ち越し秒数に応じた予定DMGを任意の基準点として登録できます。

```text
40秒以上: 20,000万
60秒以上: 32,000万
```

この場合、50秒の結果には40秒以上の予定DMGを採用します。

- 基準点は任意の数だけ追加可能
- 基準点の間では、結果秒数以下で最も大きい基準秒数を採用
- 最小基準秒数未満は持ち越しDMGを0として評価
- 90秒基準が未指定の場合、最後の担当者の予定DMGを採用
- 90秒基準を指定した場合、指定した予定DMGを採用
- 入力内容をブラウザーへ自動保存
- 基準一覧をクリップボードへコピー
- 「クリア」で保存済みの基準も削除

## 結果の並び順

持ち越しDMG基準がすべて有効な場合は、次の値が高い順に表示します。

```text
持越込残総DMG = 残総DMG + 持ち越しDMG
```

見出し:

```text
結果（持ち越しDMG含む評価順）
```

次の場合は持ち越しDMG設定を使用しません。

- 基準が1件もない
- 秒数または予定DMGに空欄がある
- 数値として無効な入力がある
- 同じ基準秒数が重複している

設定を使用しない場合は、持ち越し秒数が長い順に表示します。

```text
結果（持ち越し秒数順）
```

## 出力

- 計算結果のコピー
- CSV出力
- TXT出力
- 候補者一覧のコピー
- 持ち越しDMG基準のコピー

計算結果には、順位、組み合わせ、最後の担当、残メンバー、持ち越し秒数、残総DMGなどを含みます。持ち越しDMG基準が有効な場合は、持ち越しDMGと持越込残総DMGも含みます。

## 使い方

1. `index.html`をブラウザーで開きます。
2. 残りHPを入力します。
3. 各候補者の参加者名と予定DMGを入力します。
4. 持越凸の参加者がいる場合はチェックします。
5. 必要に応じて「詳細」を開き、計算条件と持ち越しDMG基準を設定します。
6. 「全組み合わせを計算」を押します。
7. 結果行をタップまたはクリックすると詳細を確認できます。
8. 必要に応じてコピー、CSV出力、TXT出力を使用します。

## GitHub Pagesで公開する方法

### 推奨構成

```text
repository/
├── index.html
├── README.md
└── archive/
    └── co_time_calc_optimizer_v0.html
```

- `index.html`: 公開する最新版
- `README.md`: この説明ファイル
- `archive/`: バージョン別の保管場所

### 公開手順

1. `co_time_calc_optimizer_v0.html`を複製します。
2. 複製したファイル名を`index.html`へ変更します。
3. `index.html`と`README.md`をGitHubリポジトリへアップロードします。
4. リポジトリの **Settings** を開きます。
5. **Pages** を開きます。
6. **Source**を`Deploy from a branch`にします。
7. **Branch**を`main`、フォルダーを`/ (root)`にします。
8. **Save**を押し、発行されたURLで動作を確認します。

## データ保存とプライバシー

- 計算はブラウザー内で実行されます。
- サーバーやデータベースへの送信処理はありません。
- 持ち越しDMG基準はブラウザーのローカルストレージへ保存されます。
- ブラウザーのサイトデータを削除すると保存設定も削除されます。
- 設定は別のブラウザーや別端末には自動共有されません。

## 対応環境

スマートフォンとPCのモダンブラウザーを対象としています。

- Safari
- Google Chrome
- Microsoft Edge
- Firefox

ファイルアプリなどのHTMLプレビューではJavaScriptが制限される場合があります。すべての機能を使う場合は、SafariやChromeなどのブラウザーで開いてください。
